# Venue Booking App (Bron24-like)

## 📌 О проекте

Проект — веб-приложение для бронирования спортивных площадок, вдохновлённое
мобильным приложением **Bron24**. Пользователь может просматривать площадки,
искать нужную, смотреть детали конкретной площадки и бронировать доступное
время.

Приложение реализовано на **Next.js (App Router)** с упором на современный
frontend-стек, локализацию и удобный UX.

---

## 🧱 Стек технологий

- **Next.js 16 (App Router)**
- **TypeScript**
- **TanStack Query (React Query)** — работа с серверным состоянием
- **Axios** — HTTP-запросы
- **Zustand** — клиентское состояние
- **shadcn/ui + Tailwind CSS** — UI и стили
- **React Hook Form** — работа с формами
- **Zod** — валидация данных
- **next-intl** — интернационализация (i18n)
- **Toast notifications** — уведомления

---

## ✅ Реализованный функционал

- Получение списка площадок
- Поиск площадок
- Отображение одной площадки (`/venues/[id]`)
- Настройка и просмотр информации о площадке
- Бронирование площадки
- Авторизация по OTP
- Страница **«Мои бронирования»**
- Удаление бронирования
- Интеграция **next-intl** (мультиязычность)
- Тёмная и светлая тема (частично)
- Лоадеры (текстовые)
- Proxy (реализован частично)

⚠️ **Примечание по proxy** Из-за ограничений `next-intl` не удалось реализовать
полноценный `protected proxy`. В результате используется временное клиентское
(костыльное) proxy-решение.

## 🔐 Авторизация

Авторизация реализована через OTP:

- `POST /auth/sendOtp` — отправка OTP
- `POST /auth/verifyOtp` — подтверждение OTP

После успешной авторизации:

- Получение пользователя через `GET /me`
- ID пользователя используется для бронирований

---

## 🏟 Площадки и бронирование

### API

- `GET /venues` — список площадок
- `GET /venues/[id]` — получение одной площадки

### Бронирование

- Бронирования реализованы **на клиенте**
- Данные сохраняются в `localStorage`
- Пользователь может:
  - создать бронь
  - просмотреть свои брони
  - удалить бронь

## 🌍 Локализация (i18n)

Используется библиотека **next-intl**.

### Как добавить новый язык

1. В файле `i18n/routing.ts`:
   - добавить новый язык в `locales`

2. В корне проекта:
   - создать папку с таким же названием, как язык (например `en`, `ru`, `uz`)

3. Внутри папки:
   - создать файл `common.json`

Пример структуры:

```
/locales
  /en
    common.json
  /ru
    common.json
  /uz
    common.json
```

## 🚀 Запуск проекта (без Docker)

### 1. Клонировать репозиторий

```bash
git clone <repo-url>
cd <project-folder>
```

### 2. Установить зависимости

```bash
npm install
# или
yarn install
```

### 3. Создать `.env` файл

```env
NEXT_PUBLIC_API_URL=your_api_url
```

### 4. Запуск в режиме разработки

```bash
npm run dev
# или
yarn dev
```

Приложение будет доступно по адресу:

```
http://localhost:3000
```
